# Bitaxe Orelane

Bitaxe Gamma + ORE controller with Telegram bot, Phoenix perps via Vulcan, Helius DAS wallet, and a Next.js dashboard.

## Quick reference

```bash
cd /Users/8bit/Downloads/solana-clawd/bitaxe-orelane
cp .env.example .env
npm install
npm test                       # vitest suite
npm run status                 # dry-run live snapshot
npm run bot                    # Telegram bot
npm start                      # full control loop
```

See `INTEGRATION.md` for architecture details and `GROK.md` for the Grok handoff context.
