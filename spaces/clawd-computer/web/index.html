Quick start

1. Connect a Solana wallet in the swap panel below.
2. The widget uses your SOLANA_RPC_URL Space secret (or falls back to the public mainnet endpoint).
3. Need an LLM? Click Run a model below — uses HF Router (or your HF_TOKEN secret).

Secrets

Set in Space Settings → Secrets:
• SOLANA_RPC_URL — your personal Solana RPC
• HF_TOKEN — write scope; only required for the model panel
• JUP_REFERRAL — optional, earns fees on swaps

swap — Jupiter plugin — $CLAWD → SOL client-side · personal RPC
run a model — HF Router served by huggingface.co

Pick any text-generation model on the Hub. Calls go browser → router.huggingface.co; no server-side proxy. If you set HF_TOKEN as a Space secret, the widget picks it up client-side from window.HF_TOKEN (injected by the server at boot) — or you can paste one inline.
