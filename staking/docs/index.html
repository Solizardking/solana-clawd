Non-Custodial Staking

Your agent NFT stays in your wallet. The program adds a FreezeDelegate plugin making it non-transferable — no escrow, no wrapping, no risk of losing your asset.

⚡

Metaplex Core Native

Agents are MPL Core assets with AgentIdentityV2 plugins. The staking program composes with the full Metaplex agent registry, executive delegation, and token finance stack.

🏦

Off-Chain Reward Settlement

On-chain claims emit events that the backend treasury wallet monitors. CLAWD transfers happen off-chain, keeping the program lean and the trust surface minimal.

Staking Guide

Stake your CLAWD agent in 5 steps. No custody, no wrapping, no middleware.

1

Register an Agent on Metaplex

Your agent must be a Metaplex Core asset with an AgentIdentityV2 plugin. Use the Metaplex Agent Registry SDK to mint and register in one call.

import { mintAndSubmitAgent, mplAgentIdentity } from '@metaplex-foundation/mpl-agent-registry'
import { createUmi } from '@metaplex-foundation/umi-bundle-defaults'
import { keypairIdentity } from '@metaplex-foundation/umi'

const umi = createUmi('https://api.devnet.solana.com')
  .use(mplAgentIdentity())
umi.use(keypairIdentity(umipKeypair))

const result = await mintAndSubmitAgent(umi, {}, {
  wallet: umi.identity.publicKey,
  name: 'My Clawd Agent',
  uri: 'https://arweave.net/agent-metadata.json',
  agentMetadata: {
    type: 'agent',
    name: 'My Clawd Agent',
    description: 'An autonomous Clawd agent',
    services: [{ name: 'trading', endpoint: 'https://myagent.ai/trade' }],
    registrations: [],
    supportedTrust: [],
  },
})
console.log('Agent asset:', result.assetAddress)
2

Initialize the Global Pool (Admin)

The protocol admin initializes the global staking authority. This is a one-time setup.

npm run script:devnet -- init
3

Stake Your Agent

Connect your wallet, provide the agent asset and collection addresses. The program verifies you own the asset, then adds a FreezeDelegate plugin — your agent is now staked but still in your wallet.

npm run script:devnet -- stake \
  --asset  \
  --collection
4

Claim Rewards

Rewards accrue at 1,000 CLAWD base-units per second (~86 CLAWD/day). Claim them whenever you want. The on-chain claim emits an event; the backend transfers CLAWD to your wallet.

npm run script:devnet -- claim --asset

5

Unstake When Ready

Unstaking removes the FreezeDelegate plugin and closes the staking record. Your agent is fully transferable again. Either you (the owner) or the admin (emergency) can unstake.

npm run script:devnet -- unstake \
  --asset  \
  --collection

Register an Agent

Bind an identity record to an existing MPL Core asset. Creates a PDA and attaches AgentIdentity plugin with lifecycle hooks.

await registerIdentityV1(umi, {
  asset: assetPublicKey,
  collection: collectionPublicKey,
  agentRegistrationUri: 'https://example.com/reg.json',
}).sendAndConfirm(umi)

Agent Token Launch

Launch a token from your agent's on-chain wallet using the Genesis protocol and Metaplex API.

⚡ One Token Per Agent, Forever

Each registered agent can only ever have one token. The setAgentTokenV1 instruction writes the token mint into the AgentIdentityV2 PDA — permanent, irreversible, and transparent on-chain.

$ mplx genesis launch create --launchType bonding-curve \ --name "My Agent Token" \ --symbol "MAT" \ --image "https://gateway.irys.xyz/your-image-hash" \ --agentAsset \ --agentSetToken Token launched! Mint address: View at: https://www.metaplex.com/...
🚀

Bonding Curve

Constant-product AMM starts trading immediately. Creator fees route to the agent's Asset Signer PDA. Auto-graduates to Raydium CPMM when filled.

💰

First Buy

Reserve the first swap for the agent PDA at a specified SOL amount — fee-free. Configures the initial price point on the curve.

launch: { firstBuyAmount: 0.1 } // 0.1 SOL, fee-free
🏛️

Creator Fees

Configurable percentage per swap, routing to the agent PDA. Continues accruing post-graduation from Raydium CPMM trading.

Agent Commerce

How CLAWD agents earn revenue, pay for services, and transact on-chain.

🌐

EIP-8004 Compatible

Every agent registration emits an EIP-8004-compliant metadata document. Services, endpoints, skills, and domains are discoverable by any EIP-8004 consumer.

💳

x402 Ready

Agent metadata includes an x402Support flag so HTTP 402 stablecoin payment clients can discover machine-to-machine payment capability.

🤝

Agent-to-Agent Coordination

Agents discover each other through registrations, pay each other via PDA wallets, and settle on-chain through executive-signed transactions.

🔐

Asset Signer PDA

Each agent has a deterministic wallet derived from its Core asset. No private key — controlled exclusively through MPL Core's Execute lifecycle hook.

const assetSigner = findAssetSignerPda(umi, { asset })
// No private key exists. Can only sign via Execute hook.

Security & Transparency

This code is fully open-source. No private keys. No hidden backdoors. Full audit trail.

🔍

Verified No Private Keys

The repository has been scanned — no *.json, *.pem, *.key, wallet*, secret*, private*, or .env* files exist. The .gitignore explicitly blocks all of these patterns.

🏗️

Deterministic PDAs

The Asset Signer wallet is a PDA with no private key. It cannot be stolen, leaked, or compromised. Only the MPL Core program can authorize transactions from it via the Execute lifecycle hook.

🔄

Revocable Delegation

Executive authority is per-asset and revocable. The asset owner can revoke delegation at any time, giving full control back to the owner.

📜

On-Chain Events

Every stake, unstake, and claim emits typed on-chain events. Anyone can index the event stream to verify reward accrual and protocol activity — no off-chain trust required.

🛡️

Owner Always Wins

The NFT owner can always unstake their asset. The admin has emergency-unstake capability for recovery scenarios, but the decoded Core asset owner is always validated on-chain.

✅

Fully Open Source

100% of the Solana program, CLI, tests, and documentation are in this repository. MIT licensed. No obfuscation, no closed-source components.
