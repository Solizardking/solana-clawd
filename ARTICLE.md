## X. The Agent Wallet

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│   The hardest problem in agentic finance:                        │
│   How does an AI control money safely?                           │
│                                                                  │
│   The wrong answer: give it your private key.                    │
│   The right answer: give it a permission model.                  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**AgenticWallet** gates every transaction through three layers:

```
User intent ──▶ Grok screens ──▶ Permission check ──▶ Sign & send
                    │                   │
                    ▼                   ▼
              "This looks like    { swap: "ask"
               a honeypot.         maxSwapUsd: $50
               Rejecting."         transfer: "deny" }
```

```typescript
const agent = new AgenticWallet(wallet, {
  permissions: {
    swap: "allow",        // auto-approve swaps
    transfer: "ask",      // ask user for transfers
    signMessage: "deny",  // never sign arbitrary messages
    maxSwapUsd: 200,      // hard cap per swap
  },
  onPendingTransaction: async (tx) => {
    console.log(tx.description); // "Swap 0.1 SOL → 15.23 USDC (0.12% impact)"
    return await askUser("Approve?");
  },
});

const { signature } = await agent.agentSwap({
  inputToken: "SOL",
  outputToken: "USDC",
  amount: "100000000",   // 0.1 SOL
  slippageBps: 50,
});
```

## XIV. What We Learned Building This

These are not opinions. These are scars.

```
┌───────────────────────────────────────────────────────────────────────┐
│  1. Build on-chain first.                                             │
│     The chain is truth. The API is a shortcut that will break.        │
│                                                                       │
│  2. x402 > subscription.                                              │
│     Per-call > per-month. Agents pay agents. Subscriptions die.       │
│                                                                       │
│  3. CAAP/1.0 > API keys.                                              │
│     Your keypair IS your identity. Sign everything. Share nothing.    │
│                                                                       │
│  4. AVM / Anchor versions matter.                                     │
│     Lock them. anchor_version = "0.32.1". Drift and you rebuild.      │
│                                                                       │
│  5. ESM is the present. CJS is the past.                              │
│     Don't mix them without knowing exactly why. You will lose.        │
│                                                                       │
│  6. TypeScript strict mode finds real bugs.                           │
│     Don't weaken it to ship faster. You will pay later.               │
│                                                                       │
│  7. The @coral-xyz/anchor Program constructor changed.                │
│     (idl, provider) — not (idl, programId, provider). Read changelogs.│
│                                                                       │
│  8. createSolanaRpcSubscriptions broke.                               │
│     Poll getSignatureStatuses instead. The subscription API is cursed.│
│                                                                       │
│  9. React hooks must be called at the top level. Always.              │
│     No exceptions. No useMemo workarounds. Read the rules of hooks.   │
│                                                                       │
│  10. Test every package before you ship.                              │
│      bash packages/test-all.sh  (10/10 must pass, every time)        │
└───────────────────────────────────────────────────────────────────────┘
```
