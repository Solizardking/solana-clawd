## `/api/pull` — Gacha Pull

```json
POST /api/pull
{"wallet": "<base58 pubkey>", "count": 1}
```

Returns agent cards with rarity tiers (Common 60% / Rare 25% / Epic 12% / Legendary 3%) and CLAWD token prizes:

| Rarity    | CLAWD Prize |
|-----------|-------------|
| Legendary | 50,000      |
| Epic      | 5,000       |
| Rare      | 1,000       |
| Common    | 100         |

**Pity system**: 10x pulls guarantee ≥ Rare on the final card.

**Verify commitment in-browser**:

```js
const hash = await crypto.subtle.digest(
  "SHA-256",
  new TextEncoder().encode(`${wallet}:${spinIndex}:${blockhash}`)
);
```
