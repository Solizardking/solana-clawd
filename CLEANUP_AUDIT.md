## Dry-Run Cleanup Helper

A helper script exists at `scripts/cleanup-audit.mjs`.

It defaults to dry-run mode and only prints audited paths:

```sh
node scripts/cleanup-audit.mjs generated
```

Available sets:

- `deps`: dependency install folders only.
- `targets`: Rust/Anchor build outputs only.
- `caches`: local tool/build caches only.
- `logs`: scratch/log files only.
- `generated`: `deps` + `targets` + `caches`.
- `all`: `generated` + `logs`.

Deletion requires the explicit `--apply` flag and should only be run after approval:

```sh
node scripts/cleanup-audit.mjs --apply generated
```
